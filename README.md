# My project

First-person museum sorting prototype (Unity 6 / URP).

## Setup

1. Open in Unity 6000.5.1f1 or newer.
2. Open `Assets/Scenes/SampleScene.unity`.
3. Press Play.

## Editor menu items

- **Game → Setup Zero-to-One Prototype** — room, player, lighting
- **Game → Setup Art Pickup Test** — interactable layer, pickup, test painting
- **Game → Setup Museum Gameplay** — wall mounts, HUD, extra paintings
- **Game → Fix Carry Settings** — reset hold point position

## Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Mouse | Look |
| Left click | Pick up / place on wall / drop |
| Space | Jump |
